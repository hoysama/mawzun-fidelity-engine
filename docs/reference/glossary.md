# المسرد (مصطلحات موزون)

| المصطلح | English | التعريف |
| --- | --- | --- |
| موزون | Mawzun | اسم المنصة؛ مقياس **أمانة النقل** بين نص شرعي أصلي ونص مشتق منه |
| أمانة النقل | Fidelity of Transmission | بقاء المعنى الشرعي كما هو بعد الترجمة أو التلخيص أو إعادة الصياغة |
| الانزياح الدلالي | Semantic Drift | انحراف المعنى رغم سلامة الصياغة اللغوية (مثل تحويل المنع إلى ترجيح) |
| الاقتباس المخترع | Fabricated Quote | اقتباس لا يوجد في النص حرفيًا؛ تُرفض الواقعة التي تحمله |
| بنك القيود | Constraint Bank | القيود المعتمدة في المحرك (ستة أنواع، و«20» قيدًا)، أكثره مستورد من الحزمة العلمية المعتمدة ولكل قيد `origin` |
| قوة الحكم | Ruling Force | ترميز سياسة (منع/إيجاب/استحباب/كراهة/إباحة) بإلزام واتجاه، يُبحث فلا يُجتهد |
| الطبقة الحتمية | Deterministic Layer | الأرقام والإحالات وألفاظ درجة الثبوت، بلا نموذج |
| الطبقة المعجمية | Lexical Layer | المصطلح ومقابله، وقوة الحكم، وأدوات الشرط والحصر، بحثًا في جداول |
| الحصر | Restriction (Exclusivity) | أداة تقيّد الحكم بما بعدها («إنما»، «فقط»)؛ إسقاطها يوسّع حكمًا محصورًا |
| الطبقة الدلالية | Semantic Layer | نموذج يُنتج وقائع لا أحكامًا، وكل اقتباس يُتحقق منه حرفيًا |
| الواقعة | Finding | عنصر واحد: طبقة، ونوع، وتصنيف، وموضع، ودليل (نص الأصل ونص المشتق) |
| الحكم ثلاثي الحالات | Tri-state Verdict | مطابق / يحتاج تعديل / وقف وتحويل، بقاعدة حتمية من الوقائع |
| مطابق | Faithful | لا انزياح في أي قيد مطبَّق ولا فجوة جوهرية، ويمرّ فحص الاكتمال |
| يحتاج تعديل | Needs Revision | رُصد انزياح أو إسقاط أو فجوة تمنع الشهادة |
| وقف وتحويل | Refer | النظام يمتنع عن الحكم: مستوى د، أو لا قيد مطبَّق |
| السجل المختوم | Sealed Record | سجل `SHA-256` يحمل النصين والبنك والوقائع والحكم، ويُعاد التحقق منه |
| المتن / السند | Matn / Sanad | متن الحديث وسلسلة رواته ودرجة ثبوته |
| المقاصد | Maqasid | الأغراض والغايات الشرعية للخطاب |
| النية | Niyyah (Intention) | القصد القلبي الباطن؛ مناط صحة العمل وقبوله |
| مصدر الحقيقة | Single Source of Truth | ملف واحد مرجعي (`stages.ts`) تُشتق منه الأقسام كلها |

## مصطلحات تقنية

| المصطلح | التعريف |
| --- | --- |
| App Router | موجّه التطبيق في Next.js 16 المعتمد على المجلدات |
| Server Component | مكوّن يُنفَّذ على الخادم افتراضياً بلا جافاسكربت للعميل |
| `@theme` | كتلة Tailwind v4 لتعريف رموز التصميم كمتغيّرات CSS |
| `WorkflowCard` / `Stepper` | قسم العمل المرقّم وشريط المراحل الخمسة في مساحة العمل |
| `AuditProvider` | مزوّد حالة الفحص: المدخلات، والنتيجة، والسجل، والتحقق |
| مرساة القسم | معرّف المرساة `#step-N` الذي يربط المرحلة بقسمها في الصفحة |

راجع [فحص أمانة النقل](../workflow/fidelity-audit.md) و[مسار التدقيق](../workflow/audit-pipeline.md)
و[مبدأ الحماية الدلالية](../workflow/semantic-guard.md) لسياق استخدام هذه المصطلحات.
