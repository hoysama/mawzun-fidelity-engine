# محرك التوثيق

التوثيق كله ملفات **Markdown** في مجلد `docs/` داخل المستودع: ملف واحد يساوي صفحة واحدة،
والمجلد يساوي قسمًا. لا قاعدة بيانات ولا CMS — المستودع هو مصدر الحقيقة، وتُقرأ الصفحات مباشرة
على GitHub.

> **تغيّر معماري:** كان هناك مركز توثيق يُعرض داخل التطبيق على المسار `/docs` عبر محرّك في
> `src/lib/docs/` يقرأ هذه الملفات ويولّدها ساكنًا. أُزيل ذلك المركز مع مسارات المراحل، لمّا
> صارت الواجهة صفحة واحدة. لم يبقَ من محرّك التوثيق إلا **ملفات Markdown نفسها** وسكربت الفحص
> [`scripts/check-docs.mjs`](https://github.com/Asrar-7r/mawzun-project/blob/main/scripts/check-docs.mjs).

## الأقسام

الأقسام المعروفة (يجب أن تطابق قائمة `SECTIONS` داخل سكربت الفحص):

`getting-started` · `architecture` · `workflow` · `reference` · `adr`

أي مجلد آخر تحت `docs/` لا يُفحص.

## إضافة صفحة جديدة

1. أنشئ ملف `docs/<section>/<slug>.md` داخل قسم موجود.
2. ابدأ الملف بترويسة أمامية تحدد الترتيب والبيانات الوصفية:

```md
---
title: عنوان الصفحة
description: جملة واحدة تظهر تحت العنوان وفي نتائج البحث.
order: 3
---

# عنوان الصفحة

المحتوى...
```

3. اربط الصفحات بمسارات مطلقة (`/docs/architecture/overview`) لا نسبية، ليبقى الرابط صالحًا
   ويفحصه `docs:check`.
4. تحقّق قبل الدفع:

```bash
bun run docs:check   # ترويسات + ترتيب + روابط داخلية
bun run lint         # فحص الكود
```

## قواعد الترويسة والترتيب

- `title` و`description` و`order` إلزامية في كل ملف عدا `docs/README.md` (صفحة الهبوط).
- `order` عدد صحيح يحدّد الترتيب داخل القسم.
- لا تُكرّر نفس `order` مرتين داخل القسم الواحد — يلتقطها `docs:check`.

## ماذا يفحص `docs:check`؟

سكربت `scripts/check-docs.mjs` يمرّ على الأقسام الخمسة وملفاتها `.md`، ويُبلّغ عن:

- ترويسة ناقصة (`title` أو `description` أو `order`) في أي صفحة؛
- `order` ليس عددًا صحيحًا، أو مكرّرًا داخل القسم نفسه؛
- رابط داخلي مكسور بصيغة `/docs/...` لا يقابل صفحة موجودة (ويستثني `/docs` في صفحة الهبوط)؛
- قسم مفقود أو فارغ.

عند النجاح يطبع عدد الصفحات التي رآها (يتغيّر مع كل صفحة تُضاف)، مثل:

```text
✓ docs:check passed — <n> pages across 5 sections.
```

## كيف تكتب الروابط؟

- الروابط الداخلية بين الصفحات بصيغة مطلقة: `[المكوّنات](./components.md)`.
- مراسي الأقسام داخل الصفحة (`#...`) حرة ولا يفحصها السكربت.
- الروابط الخارجية (مثل `AGENTS.md` على GitHub) تُكتب كاملة.

راجع [المكوّنات](./components.md) لواجهات مكوّنات الواجهة، و
[الاصطلاحات البرمجية](../reference/conventions.md) لقواعد الفروع والوسوم قبل المساهمة.
